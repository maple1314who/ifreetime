📚 API 使用示例

# Edge TTS（默认）
curl -X POST http://localhost:3000/v1/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"你好世界"}'

# MiMo TTS
curl -X POST http://localhost:3000/v1/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"你好世界","provider":"mimo","voice":"alloy","token":"your-api-key"}'

# 获取语音列表
curl http://localhost:3000/v1/voices?provider=edge
